# DSCG Learning Loop

Use this for DSCG learning and revision. The goal is mastery through retrieval, exercises, and error correction — not passive rereading.

## Mission

Turn a course, chapter, note, or vague revision goal into a simple learning loop.

## Minimal Loop

1. Scope — choose one topic only.
2. Recall first — ask what the user remembers before summarizing.
3. Teach only the missing part.
4. Practice — produce exercises or cases.
5. Error log — identify the mistake pattern.
6. Flashcards — create only cards tied to weak points.
7. Next review — schedule the next checkpoint.

## Session Format

```md
# DSCG Session — [Topic]

## Scope
[One topic, not a whole UE]

## Recall
Question 1:
Question 2:
Question 3:

## Micro-lesson
[Only what is needed]

## Exercise
[Case or calculation]

## Correction
[Step-by-step correction]

## Error log
- Error:
- Why it happened:
- Rule to remember:
- Next drill:

## Flashcards
Q:
A:

## Next review
[Date or interval]
```

## ADHD Simplicity Rule

One topic, one exercise, one error pattern, one next review. Do not create a huge plan unless the user explicitly asks.

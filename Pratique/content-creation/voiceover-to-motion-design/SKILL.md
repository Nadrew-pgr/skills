# Skill — Voice-over to Motion Design

## Goal

Transform a script or voice-over into a full motion design plan.

This skill is used when there is no facecam or when the video should be mostly motion graphics.

## Inputs

- script or transcript;
- voice-over timing if available;
- target platform;
- brand system;
- reference videos;
- required CTA.

## Process

1. Segment the voice-over into beats.
2. Define the visual thesis.
3. Choose a metaphor: system map, document graph, agent cards, prompt flow, workflow pipeline, etc.
4. Create shot list.
5. Define hero frame.
6. Define visual objects.
7. Define motion paths.
8. Define transitions.
9. Choose existing HyperFrames components or specify custom motion.
10. Create storyboard.
11. Add QA timestamps.

## Output format

Return:

- visual thesis;
- beat table with timestamps;
- shot specs;
- hero frame;
- object list;
- component decisions;
- custom motion needs;
- visual QA checklist.

## Non-negotiable

Motion must clarify the idea. If the motion only looks cool but does not explain, simplify.

## Skills

Source canonique des skills réutilisables maintenus dans le vault.

## Domaines

- [[Technique/_index|Technique]] — Skills pour construire : développement logiciel, agents, sécurité, expériences web et design.
- [[Pratique/_index|Pratique]] — Skills pour travailler : réflexion, apprentissage, notes, médias, création de contenu et intégrations.

## Règle

- Les skills sont classés par domaine (Technique / Pratique), puis par compétence.
- Un skill peut exister dans les deux domaines quand il sert aux deux contextes.
- La copie active dans un outil comme Codex peut exister ailleurs, mais la source de vérité reste ici.

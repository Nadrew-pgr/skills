# External Sources

Use external sources as optional references, not as the only source of truth. Network may be unavailable, repositories may change, and project constraints override generic recommendations.

## UI/UX Knowledge

- UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
  - Useful for broad UI/UX patterns, palettes, typography, product-type heuristics, accessibility and design-system thinking.
  - Do not copy the whole repository into this skill. Use it as inspiration or dependency with attribution when needed.

## Agentic Components

- 21st.dev: https://21st.dev
- Agent Elements: https://21st.dev/community/blog/agent-elements
  - Useful for agentic UI patterns such as composer/input bar, tool cards, plan approvals, markdown, edit/plan tools.
  - For landing pages with an AI input moment, often only the input surface and one or two approval/status components are needed.

## 3D Storytelling / Immersive Production

- Noomo — 3D Video Storytelling: https://noomoagency.com/insights/3d-video-storytelling-product-launches
- Noomo — Immersive Event Experience Design: https://noomoagency.com/insights/immersive-event-experience-design-enterprise-brands
- Noomo — Vibrant Wellness Immersive Experience: https://noomoagency.com/insights/creating-immersive-event-experience-for-vibrant-wellness
- Noomo — Implement 3D Animation on Websites: https://noomoagency.com/insights/easy-way-to-implement-3d-in-web
- Noomo — Digital Storytelling: https://noomoagency.com/insights/the-power-of-digital-storytelling
  - Useful heuristics: story first, behavior before look, spatial logic, hybrid 2D/3D, performance as design, visual QA after major changes.
  - Do not copy their marketing positioning blindly; adapt principles to the current project.

## Principle

Prefer project-native components and tokens first. Use external component sources when they reduce risk or improve accessibility/coherence, then adapt them to the product’s design system.

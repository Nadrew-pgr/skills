# Skill — HyperFrames Hook and Overlay

## Goal

Design hook visuals and branded overlays for a video.

## Rules

- First 2 seconds must have visual clarity.
- Text on screen, voice, and visual must promise the same thing.
- Use brand system from `branding/brand-system.md`.
- Use overlays to explain, not decorate.
- Use `branding/hyperframes-component-policy.md` before selecting components.

## Output

Return:

- hook frame concept;
- key overlays;
- words to emphasize;
- arrows/zooms/highlights;
- scenes where no overlay is better;
- component reuse/adapt/custom decision.

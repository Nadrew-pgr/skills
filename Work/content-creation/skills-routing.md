# Skills Routing

## Goal

Choose the right skill based on the content task.

## Written content

Use:

- `content-review.SKILL.md` for review;
- `content-repurposing.SKILL.md` for waterfall;
- `07-shape-framework.md` for prompt content.

## Carousel / infographic / PDF

Use:

- `content-review.SKILL.md`;
- `branding/brand-system.md`;
- `templates/carousel-brief-template.md`.

## Talking head / screen demo video

Use:

1. `video-trim-and-polish.SKILL.md`
2. `hyperframes-hook-and-overlay.SKILL.md` if branded overlays are needed
3. `video-visual-qa.SKILL.md`
4. `content-review.SKILL.md`

## Hybrid demo + motion overlays

Use:

1. `motion-design-creative-director.SKILL.md`
2. `hyperframes-component-curator.SKILL.md`
3. `hyperframes-hook-and-overlay.SKILL.md`
4. `video-trim-and-polish.SKILL.md`
5. `video-visual-qa.SKILL.md`

## Full motion explainer from voice-over

Use:

1. `voiceover-to-motion-design.SKILL.md`
2. `motion-design-creative-director.SKILL.md`
3. `hyperframes-component-curator.SKILL.md`
4. native HyperFrames skills / framework docs
5. `video-visual-qa.SKILL.md`
6. `content-review.SKILL.md`

## Rule

If the output requires motion, never call HyperFrames directly without a visual thesis, storyboard, and component decision.

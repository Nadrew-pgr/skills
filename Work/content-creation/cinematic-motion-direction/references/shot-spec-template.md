# Shot Spec Template

Use this template before coding complex motion.

```md
## Shot {number} — {name}

Intent:
- What should viewer feel/understand?

Duration:
- `{start}s -> {end}s`

Hero frame:
- Timestamp:
- Static layout:
- Must be readable:

Elements:
- Subject:
- Supporting layers:
- Text:
- Background:

Motion:
- Subject start:
- Subject path:
- Subject end:
- Camera/crop start:
- Camera/crop path:
- Camera/crop end:

Timing:
- Beat 1:
- Beat 2:
- Beat 3:

Easing:
- Entrance:
- Main move:
- Settle:
- Exit:

Transition in:
- Previous shot handoff:

Transition out:
- Next shot handoff:

Risks:
- Overlap:
- Readability:
- Motion sickness:
- Timing conflicts:

Verification:
- Screenshot/render at:
- Acceptance:
```
